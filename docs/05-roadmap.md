## M1 数据层（约 2 个开发轮次）

**目标**：不打开界面也能把记录正确存下、查出来、清理掉。

- [ ] `app/config.py`：settings 读写 + 默认值 + 类型校验（retention_days 1–365）
- [ ] `app/storage.py`：数据目录解析（exe 同目录 → LOCALAPPDATA 回退）、图片保存、缩略图生成、sha256、文件删除
- [ ] `app/db.py`：建表 + schema 版本；`upsert_item` / `list_items` / `search` / `toggle_pin` / `delete_item` / `purge_expired` / `count`
- [ ] `tests/test_db.py`：去重更新时间、置顶排序、搜索转义、删除连带文件、清理豁免置顶、分页
- [ ] `tests/test_storage.py`：临时目录保存/删除/回退逻辑
- [ ] 临时脚本 `tools/dev_smoke.py`：插入 20 条假数据并打印列表，肉眼确认

**交付物**：可被 M2/M3 直接调用的三个模块 + 全绿测试。
**验收**：`python -m unittest discover -s tests -v` 全绿；`tools/dev_smoke.py` 输出正确的降序列表。
**依赖**：无。
**风险**：时间格式与排序（统一 ISO8601 字符串）；图片路径用相对路径，搬家后仍可读。

## M2 系统能力层（约 2 个开发轮次）

**目标**：能真正读到剪贴板，且读得稳。

- [ ] `app/win32.py`：剪贴板打开/关闭（带重试）、读文本、写文本、写图片（CF_DIB）、`GetClipboardSequenceNumber`、排除标记检测、`RegisterWindowMessageW`
- [ ] `app/clipboard.py`：`ClipboardListener` 线程（500ms 轮询）、内容规范化纯函数 `normalize_text`、大小/尺寸上限判断、去重入库、`queue` 事件
- [ ] `tests/test_clipboard.py`：规范化（去空白、超长丢弃）、上限判断（用假对象）、hash 稳定
- [ ] 手动验证：复制文字/图片/文件，日志显示入库结果

**交付物**：后台线程能自动入库。
**验收**：复制 5 段文字 + 2 张图，`history.db` 出现 7 条；重复复制不新增；复制图像文件也识别。
**依赖**：M1。
**风险**：剪贴板被 Office/远程桌面占用时读取失败 → 重试 + 跳过；`ImageGrab` 在无控制台进程下的表现需实测。

## M3 界面骨架（约 2 个开发轮次）

**目标**：一个能看、能滚动、符合设计规范的窗口（暂无交互逻辑）。

- [ ] `app/ui/theme.py`：设计令牌常量（颜色/字体/尺寸），`apply_root_style`
- [ ] `app/ui/main_window.py`：顶栏（标题/搜索/设置/最小化/关闭）、列表 Canvas + 滚动、底部状态栏、空状态
- [ ] `app/main.py`：DPI 感知、日志、建库、启动监听线程、`after` 轮询队列、刷新列表
- [ ] `docs/03` 对照自查：色值、间距、字号全部来自 theme

**交付物**：`python app/main.py` 能打开窗口并显示真实历史。
**验收**：复制内容后窗口顶部出现卡片（先只渲染文字预览）；125% 缩放不模糊；关闭窗口进程仍在。
**依赖**：M1（数据）、M2（可选，先用假数据）。
**风险**：Canvas 内嵌 Frame 的尺寸计算（用 `update_idletasks` + `bbox("all")` 设 scrollregion）。

## M5 生命周期与设置（约 2 个开发轮次）

**目标**：像一个真正的常驻软件那样活着。

- [ ] 全局热键线程（`Ctrl+Shift+V`）+ 唤出置前 + 注册失败告警与备选键
- [ ] 单实例（互斥体 + 广播唤起）
- [ ] 关闭到后台 + 首次提示；「彻底退出」确认与清理（停线程、注销热键、关库）
- [ ] 清理定时器（启动一次 + 每 10 分钟）
- [ ] `app/ui/dialogs.py` 设置面板：保留期（1/3/5/7 + 自定义）、热键、清空历史、数据目录、版本
- [ ] 窗口几何记忆

**交付物**：FR-01、FR-10、FR-13、FR-14、FR-15 可用。
**验收**：关闭窗口后热键唤出；重启双击不产生第二进程；保留期到点自动清理。
**依赖**：M4。
**风险**：热键线程的消息循环要与主线程隔离；退出时要 `PostThreadMessage(WM_QUIT)` 才能干净结束。

## 每轮任务的标准动作

1. 读 `docs/05`（本节）+ 当天 `devlog` + 相关设计文档。
2. 写本轮 todo（≤4 项）。
3. 实现 → 自测（`unittest` + 手动跑一次）。
4. `python tools/devlog.py done "..."` / `todo "..."`。
5. 更新本文件状态表，向用户汇报「做了什么 / 结果 / 下一步」。

## 暂停点（必须停下来等用户确认）

- 每个里程碑完成时。
- 需要引入新技术/新依赖时。
- 需要改变已确认需求（如热键、保留期规则、密码策略）时。
- 打包产物第一次交付时。
