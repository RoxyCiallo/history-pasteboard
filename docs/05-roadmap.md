## M2 系统能力层 ✅（2026-10-21）

**目标**：能真正读到剪贴板，且读得稳。

- [x] `app/win32.py`：剪贴板打开/关闭（带重试）、读文本、写文本、写图片（CF_DIB）、`GetClipboardSequenceNumber`、排除标记检测、`RegisterClipboardFormatW`
- [x] `app/clipboard.py`：`ClipboardListener` 线程（500ms 轮询）、内容规范化纯函数 `normalize_text`、大小/尺寸上限判断、去重入库、`queue` 事件
- [x] `tests/test_clipboard.py`：规范化（去空白、超长丢弃）、上限判断（用假对象）、hash 稳定、入库编排（文本优先/私密/去重/图片落盘）
- [x] `tools/clipboard_watch.py`：手动验证脚本（监听 30 秒并实时打印）
- [x] 手动验证：复制文字/图片/图片文件，日志显示入库结果

**交付物**：后台线程能自动入库。
**验收结果**：实测复制 3 段文字（其中 1 段重复）+ 1 张剪贴板图片 + 1 个图片文件 → 数据库 4 条、重复内容只刷新时间、“文件形式复制的图片”被识别为图片卡。全量测试 `Ran 64 tests ... OK`。
**说明**：`RegisterHotKey`（Ctrl+Shift+V）与单实例互斥体按路线图归入 **M5**，本轮未做。
**风险**：剪贴板被 Office/远程桌面占用时读取失败 → 重试 + 跳过；`ImageGrab` 在无控制台进程下的表现需实测。

## M3 界面骨架 ✅（2026-10-21）

**目标**：一个能看、能滚动、符合设计规范的窗口（暂无交互逻辑）。

- [x] `app/ui/theme.py`：设计令牌常量（颜色/字体/尺寸），`apply_root_style`
- [x] `app/ui/main_window.py`：顶栏（标题/搜索/设置/最小化/关闭）、列表 Canvas + 滚动、底部状态栏、空状态
- [x] `app/main.py`：DPI 感知、日志、建库、启动监听线程、`after` 轮询队列、刷新列表
- [x] `docs/03` 对照自查：色值、间距、字号全部来自 theme
- [x] 全局热键 `Ctrl+Shift+V`（原属 M5，因「关闭后必须能唤回」提前到 M3）

**交付物**：`python app/main.py` 能打开窗口并显示真实历史。
**验收结果（2026-10-21）**：
- 真实进程（`python.exe`）端到端：启动日志正常、`Set-Clipboard` 复制两条文本被记录（id=1/2）并出现在列表顶部，监听线程 → 队列 → `_poll_events` → `refresh` 闭环成立。
- 窗口 900×680（客户区），DPI 感知开启；截图 `build/m3-live2.png` 目视符合设计规范（淡蓝顶栏、白底卡片、置顶蓝竖条、状态栏）。
- 关闭窗口（`WM_CLOSE`）后窗口隐藏、进程存活、记录继续（通过 `hide_hint_shown` 首次提示）。
- 进程内自检 `build/ui_probe.py`：搜索「SELECT」过滤到 1 条、搜索无结果展示空状态、清空恢复 4 条、`hide()` 后 `winfo_viewable=0`、`show()` 后为 1。
- 64 项单元测试全绿；`compileall` 通过；UI 层无硬编码色值（只在 `theme.py`）。
- 已知限制：卡片为直角（圆角在 M4 用 Canvas 卡片组件实现）；长文本按 80 字符截断而非按实际行宽，极端窄窗口下可能超过 3 行（M4 卡片组件处理）；`Ctrl+Shift+V` 按键注入在沙箱内无法模拟，实机按键待用户验证。
**依赖**：M1（数据）、M2（可选，先用假数据）。
**风险**：Canvas 内嵌 Frame 的尺寸计算（用 `update_idletasks` + `bbox("all")` 设 scrollregion）。

## 每轮任务的标准动作

1. 读 `docs/05`（本节）+ 当天 `devlog` + 相关设计文档。
2. 写本轮 todo（≤4 项）。
3. 实现 → 自测（`unittest` + 手动跑一次）。
4. `python tools/devlog.py done "..."` / `todo "..."`。
5. 更新本文件状态表，向用户汇报「做了什么 / 结果 / 下一步」。

## 暂停点（必须停下来等用户确认）

- 每个里程碑完成时。
- 需要引入新技术/新依赖时。
- 需要改变已确认需求（如热键、保留期规则、密码策略）时。
- 打包产物第一次交付时。
