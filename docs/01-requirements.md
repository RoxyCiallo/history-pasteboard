# 01 需求规格说明书

- 版本：v1.0
- 日期：2026-10-21
- 状态：已确认（用户 2026-10-21 答复 5 项关键选择）
- 变更需用户确认，并在文末「变更记录」追加。

## 1. 背景与目标

Windows 自带的剪贴板历史（Win+V）容量小、不能搜索、图片管理弱、清理策略不可控。本项目做一个本地工具，把最近复制过的文字和图片存下来，随时找回并重新粘贴。

一句话目标：**复制过的东西不丢，一按热键就能找回、能搜索、能再粘一次。**

## 2. 用户与场景

| 场景 | 行为 |
|---|---|
| S1 找回半小时前复制的地址 | `Ctrl+Shift+V` → 顶部即最新几条 → 点击 → `Ctrl+V` 粘贴 |
| S2 找一段忘记出处的文字 | 搜索框输入关键字 → 命中卡片高亮 → 点击复制 |
| S3 复用常用片段 | 把卡片置顶，之后一直在最上方，且不会过期 |
| S4 找回截图 | 复制图片 → 列表出现缩略图 → 点击 → 原图回到剪贴板 |
| S5 别人用我电脑 | 密码类内容默认打码，看不到正文，也无法复制 |
| S6 磁盘别被塞满 | 设成保留 3 天，过期自动清理，图片文件一并删除 |

## 3. 功能需求

优先级：P0 必须、P1 应该、P2 可选（本期不做 P2 可延后）。

| 编号 | 需求 | 说明与规则 | 优先级 |
|---|---|---|---|
| FR-01 | 后台监听剪贴板 | 程序运行（含窗口已关闭隐藏）时持续记录；启动后即可用 | P0 |
| FR-02 | 记录文字 | 保留原文；去首尾空白；空内容不记；单条 > 1MB 跳过 | P0 |
| FR-03 | 记录图片 | 保存原图与缩略图；卡片显示缩略图；> 20MB 或任一边 > 8000px 跳过 | P0 |
| FR-04 | 重复内容去重 | 同一内容（sha256 相同）不新增卡片，只刷新时间并移到顶部 | P0 |
| FR-05 | 时间降序列表 | 置顶在前，其余按最近复制时间倒序 | P0 |
| FR-06 | 置顶 | 卡片可置顶/取消置顶；置顶卡片排最前，且**不受保留期清理** | P0 |
| FR-07 | 删除 | 卡片可删除，二次确认；图片文件一并删除 | P0 |
| FR-08 | 再次粘贴 | 点击卡片把内容写回系统剪贴板；**窗口保持打开**并在状态栏提示；程序自身写入的这次变化不再记为历史 | P0 |
| FR-09 | 搜索 | 顶部搜索框，输入即时过滤（文字内容模糊匹配，忽略大小写） | P0 |
| FR-10 | 保留期 | 预设 1/3/5/7 天，可自定义 1–365 天；过期卡片自动清理；置顶豁免 | P0 |
| FR-11 | 敏感内容 | 带系统「不记录」标记的复制内容记为私密：列表打码显示锁标记，查看/复制需二级密码 | P0 |
| FR-12 | 二级密码 | 首次使用私密功能时设置密码；PBKDF2 存储；错误 5 次冷却 30 秒；解锁 5 分钟后自动重新上锁 | P0 |
| FR-13 | 窗口生命周期 | 关闭按钮 = 隐藏到后台继续记录；`Ctrl+Shift+V` 唤出；主界面内「彻底退出」才结束进程 | P0 |
| FR-14 | 单实例 | 重复双击 exe 不产生第二个进程，而是唤出已运行窗口 | P1 |
| FR-15 | 设置面板 | 保留期、修改/重置密码、热键、清空历史、数据目录、版本 | P1 |
| FR-16 | 空状态与错误提示 | 无记录、无搜索结果、剪贴板被占用等都有中文提示 | P1 |
| FR-17 | 首次隐藏提示 | 第一次关窗口时提示「仍在后台运行，Ctrl+Shift+V 唤出」，只提示一次 | P1 |
| FR-18 | 查看全文 | 超过 3 行的文字卡片显示「查看全文」入口，点击弹窗展示完整内容，可一键复制 | P1 |
| FR-19 | 版本与更新日志 | 版本号 `主.次.修订` 统一由 `app/config.py` 提供，设置面板与 exe 属性同步显示；每次发版在根目录 `CHANGELOG.md` 增加条目 | P1 |

## 4. 非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| NFR-01 | 离线 | 运行期零网络请求 |
| NFR-02 | 性能 | 复制到卡片出现 ≤ 1s；5000 条历史下列表滚动流畅；搜索响应 ≤ 200ms |
| NFR-03 | 资源 | 空闲 CPU < 1%，常驻内存 < 150MB |
| NFR-04 | 可靠 | 剪贴板被占用时重试不崩溃；所有异常写 `data/app.log`；SQLite 用 WAL |
| NFR-05 | 安全 | 密码只存 PBKDF2 哈希（16B 盐，200000 次迭代）；不上传任何数据；私密内容明文落盘的限制须在 README 声明 |
| NFR-06 | 可用性 | 全中文界面；支持 125%/150% 缩放不模糊；主要操作可纯鼠标完成 |
| NFR-07 | 可维护 | 分层清晰、有单元测试、文档与代码同步 |
| NFR-08 | 绿色免安装 | **文件夹绿色版**（exe + `_internal/` + 同目录 `data/`）；不写注册表（不设开机自启）；普通用户双击即可运行，无需管理员权限；卸载 = 删除目录 |

## 5. 数据与隐私边界

- 数据全部在本机 `data/` 目录：`history.db`、`images/`、`thumbs/`、`app.log`。
- 不收集、不上传、不做统计。
- 私密卡片正文以明文存于 SQLite；密码只控制界面展示与复制（见 ADR-003）。README 必须写明该限制。
- 提供「清空全部历史」与「删除私密卡片」入口。

## 6. 明确不做（本期）

| 项 | 原因 |
|---|---|
| 系统托盘图标 | 用户要求用 `Ctrl+Shift+V` 唤出，主界面内退出（ADR-002） |
| 开机自启 | 需写注册表，与绿色版目标冲突；后续可选 |
| 云同步 / 多设备 | 与离线隐私目标冲突 |
| 富文本/HTML 保真 | 只保留纯文本，避免格式兼容问题 |
| 深色主题 | 本期只做淡蓝浅色 |
| 剪贴板内容加密存储 | 标准库无 AES；记为后续候选（ADR-003） |
| 多语言 | 仅中文 |

## 7. 验收标准（全部满足才可交付）

1. 双击 `PasteBoard.exe` 后复制文字/图片，≤1s 出现在列表顶部。
2. 点关闭按钮窗口消失，后台仍记录；`Ctrl+Shift+V` 立即唤出并置前。
3. 主界面「彻底退出」后进程结束，热键失效。
4. 卡片可置顶（排最前、不清除）、可删除（确认后）、可点击复制回剪贴板。
5. 搜索即时过滤；置顶卡片在结果中仍排最前。
6. 保留期 1/3/5/7 天与自定义 1–365 天可设；过期卡片与图片文件被清理，置顶卡片保留。
7. 私密卡片打码，查看/复制需密码；连续 5 次错误冷却 30 秒。
8. 重启程序后历史、置顶、设置、密码均保留。
9. 普通用户双击 `PasteBoard.exe`（文件夹版）即可运行，不需要管理员权限；历史数据随 `data/` 目录持久保留。
10. 点击历史卡片复制后窗口保持打开，状态栏提示已复制；该次写入不会产生新记录或把旧记录顶到最前。
11. 超过 3 行的文字卡片有「查看全文」入口，弹窗可完整查看并一键复制。
