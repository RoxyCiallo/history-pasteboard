## ADR-001 技术栈选 Python + tkinter

**背景**：需要一个 Windows 桌面程序，能在本机离线开发与打包。

**选项**
- A. Electron + SQLite：UI 表现力最好，但需下载约 100MB 运行时、原生模块编译、包体 150MB+、内存占用高。
- B. C# WPF：原生体验好，但本机无 .NET SDK 与编译链。
- C. Python 3 + tkinter + sqlite3 + Pillow + ctypes：本机全部就绪，零第三方运行时依赖。

**决定**：C。

**理由**：环境已核实可用（Python 3.12.14 / Tk 8.6 / Pillow 12.3.0 / SQLite 3.53.1）；卡片式 UI 用 Canvas 手绘可控；Win32 能力用 ctypes 直调，不引 pywin32。开发与打包全程可离线。

**后果**：UI 需手写控件样式（圆角、悬停），工作量高于 Web 技术栈；换行/富文本能力有限，因此只保留纯文本。

## ADR-002 不做托盘图标，用全局热键唤出

**背景**：程序需要「关窗口后继续记录」。常见做法是缩到系统托盘。

**用户选择**（2026-10-21）：创建 exe，双击运行；关闭窗口后仍记录；只有主界面里的按钮能彻底关闭；关闭后用 `Ctrl+Shift+V` 唤出。

**决定**：不做托盘；关闭按钮 = 隐藏；热键唤出；主界面底部「彻底退出」。

**理由**：遵循用户明确描述；省掉托盘图标资源与第三方库（tkinter 无原生托盘，需 pystray 或手写 Shell_NotifyIcon）。

**后果**：用户可能忘记程序仍在运行 → 首次隐藏时弹一次提示（FR-17）；热键被占用时必须有备选键（设置面板可切换）。

## ADR-003 二级密码仅作界面门禁

**背景**：敏感内容需要「输入密码才能查看」。

**选项**
- A. 只做界面门禁（哈希校验）。
- B. 加密正文（AES-GCM），密码派生密钥。

**决定**：A，但 README 明示限制。

**理由**：Python 标准库没有 AES，B 需引入 `cryptography` 或手写实现，违背「零第三方运行依赖」；本期以隐私边界声明 + 本地文件权限为主。同时保留 `pwd_iterations` 字段便于未来升级。

**后果**：能直接读 `data/history.db` 的人可绕过密码读到私密内容。已在 `docs/01` 第 5 节与 README 声明；加密存储列为后续候选。

## ADR-004 内容哈希去重并刷新时间戳

**背景**：同一段内容常被反复复制，逐次新增会淹没列表。

**决定**：`content_hash`（sha256）唯一索引；重复复制不新增行，只更新 `updated_at`（置顶状态不变）。

**理由**：符合「最近复制的排最上」的直觉；数据库不会膨胀；图片同样按内容去重，磁盘只存一份。

**后果**：丢失「复制了几次」的计数（本期不需要）；若用户希望保留多份副本，需后续加设置开关。

## ADR-005 置顶卡片豁免保留期清理

**背景**：保留期到点会删记录，但置顶通常意味着「我要长期留着」。

**用户选择**：置顶永久保留。

**决定**：`purge_expired` 只删 `pinned=0` 的记录。

**后果**：置顶卡片只能手动删除；用户若置顶过多，列表顶部会长期占用，属预期行为。

## ADR-006 剪贴板用轮询而非消息监听

**选项**
- A. `AddClipboardFormatListener` + 隐藏窗口消息循环：实时，但要额外窗口与线程消息泵，和 tkinter 主循环冲突。
- B. `GetClipboardSequenceNumber` 每 500ms 轮询：一次系统调用，开销近零。

**决定**：B。

**理由**：实现简单、无线程安全风险；500ms 延迟用户不可感知；失败时下一轮自然重试。

**后果**：复制后最多 0.5s 才入库；若将来要更低延迟，降到 200ms 或迁到 A（记录在此）。

## ADR-007 exe 用 ASCII 名 `PasteBoard.exe`

**背景**：产品中文名「历史粘贴板」；中文文件名在部分打包/杀软/命令行场景易出兼容问题。

**决定**：exe 名走 ASCII，窗口标题与界面文案保持中文。

**后果**：用户可自行重命名 exe（不影响运行）；分发说明里注明可改名。

## ADR-008 敏感内容记录但打码，而非丢弃

**背景**：Windows 上密码管理器复制内容时会设置 `ExcludeClipboardContentFromMonitorProcessing` 等标记。

**选项**
- A. 完全跳过不记录（多数工具默认）。
- B. 照常记录，但标记私密：列表打码、需密码查看。

**用户选择**：B —— 「设置二级密码并打上密码类标记，查看需输入密码」。

**决定**：B。

**后果**：明文落盘（见 ADR-003），需在文档中说明；首次遇到私密内容时引导设置密码。

## ADR-009 数据目录随 exe，不可写时回退 AppData

**背景**：绿色版希望「拷走目录就带走数据」，但放在 `Program Files` 等只读位置会写失败。

**决定**：优先 `exe 同目录/data/`，探测写入失败后回退 `%LOCALAPPDATA%\PasteBoard\data\`。

**后果**：同一台机器可能出现两份数据（取决于启动位置）；设置面板显示当前真实数据目录以消除困惑。
