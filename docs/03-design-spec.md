# 03 视觉与交互规范

- 版本：v1.0
- 日期：2026-10-21
- 原则：简洁、直观、淡蓝。**所有颜色只能来自第 2 节的设计令牌**，代码里禁止出现裸色值。

## 1. 设计原则

1. **一眼看到最新**：打开即看到最近复制的内容，不需要额外点击。
2. **一屏一件事**：卡片就是内容，操作按钮收在卡片边缘，不抢视觉。
3. **克制的颜色**：大面积留白 + 淡淡蓝底，主色只用于强调（搜索聚焦、置顶条、主按钮）。
4. **可预期的反馈**：任何点击都有可见结果（高亮、提示、列表变化）。

## 4. 组件规范

### 4.1 顶栏

- 高 64，底色 `BG_HEADER`，底部 1px `BORDER` 分隔。
- 左：标题「历史粘贴板」`FONT_TITLE`，`TEXT_PRIMARY`。
- 右依次：搜索框、设置按钮、最小化、关闭。
- 关闭按钮 = **隐藏到后台**（不是退出），首次点击弹一次提示（`hide_hint_shown`）。

### 4.2 搜索框

- 宽 260、高 32，圆角 6，白底 1px `BORDER`；聚焦时边框 `BORDER_FOCUS`。
- 占位文字「搜索历史…」，`TEXT_SECONDARY`；输入后 300ms 防抖再过滤。
- 有内容时右侧显示清除按钮 ×。

### 4.3 卡片

通用：
- 白底、1px `BORDER`、圆角 10、内边距 14、卡间距 10。
- 悬停：底色变 `BG_CARD_HOVER`，边框 `PRIMARY_LIGHT`。
- 左侧类型图标 16px：文字 `📄`、图片 `🖼`、私密 `🔒`（统一用文本符号渲染，避免图片资源）。

文字卡：
- 内容最多 3 行，超出显示 `…`；保留换行。
- 点击卡片正文 = 复制并隐藏窗口。

图片卡：
- 缩略图 260×150（等比缩放居中，多余留白），1px `BORDER` 圆角 6。
- 底部「宽×高 · 大小」。

私密卡：
- 底色 `BG_PRIVATE`；内容区只显示 `••••`（固定 12 个点）+ 提示文案。
- 查看按钮 → 密码框；解锁后本会话内正常显示，卡片左上角显示「已解锁」小标签。

位置元素：
- 右上角：图钉按钮（未置顶为 `TEXT_SECONDARY`，已置顶为 `PIN_ACTIVE` 实心）、删除按钮（悬停 `DANGER`）。
- 底部一行：时间 `FONT_SMALL` `TEXT_SECONDARY`，格式「今天 14:32」「昨天 09:10」「2026-10-18 21:05」。
- 置顶卡：左侧 3px `PRIMARY` 竖条 + 底部显示「已置顶」。

### 4.4 按钮

- 主按钮：`PRIMARY` 底 + `TEXT_ON_PRIMARY`，圆角 6，高 32，悬停 `PRIMARY_HOVER`。
- 次按钮：白底 + `BORDER` + `TEXT_PRIMARY`。
- 危险按钮：`DANGER` 文字；确认弹窗主按钮才是 `DANGER` 底。
- 文字按钮（图钉/删除）：无边框，仅图标，悬停加浅底。

### 4.5 对话框

- 居中于主窗口，白底圆角 8，标题 12pt bold，按钮右下对齐。
- 密码框：标题「输入二级密码」、`*` 掩码输入框、错误提示行（`DANGER`，「密码错误，还可尝试 4 次」）、按钮「取消 / 解锁」。
- 确认框：标题 + 说明（删除会连带删除图片文件）、按钮「取消 / 删除」。
- Esc = 取消，Enter = 确认。

### 4.5.1 设置面板（M5 已实现）

- 尺寸约 560×520，`BG_ROOT` 底，内边距 20；模态（`transient` + `grab_set`），Esc 关闭。
- 自上而下：标题「设置」→ 保留期 → 唤出热键 → 数据目录 → 二级密码 → 清空全部历史 → 底栏（版本号 + 取消/保存）。
- 保留期：`1 天 / 3 天 / 5 天 / 7 天 / 自定义` 单选；选「自定义」时启用右侧数字输入框，范围 1–365；下方小字说明「置顶的记录不受保留期影响」。
- 热键：只读展示当前实际注册的按键，附小字「更改热键需要重启程序，本期暂不支持」。
- 数据目录：只读输入框显示真实路径 + 「打开」按钮（资源管理器）。
- 二级密码（M6）：显示「已设置 / 未设置」；已设置时右侧「重置密码」按钮，二次确认（「会同时删除所有私密记录，且无法恢复」）后删除全部私密记录并清除密码，按钮转为禁用。
- 清空全部历史：`DANGER` 底白字按钮，二次确认后删除全部记录与图片。
- 底栏：「保存」为 `PRIMARY` 主按钮，「取消」为白底次按钮，两者右对齐；左侧小字显示 `历史粘贴板 v{版本号}`。

### 4.5.2 密码对话框（M6 已实现）

- 尺寸约 380 宽、按内容自适应；`BG_ROOT` 底、内边距 20、模态（`transient` + `grab_set`），Esc 关闭、Enter 提交。
- 两种模式：
  - **设置密码**：标题「设置二级密码」；说明两行「首次使用私密内容，请设置一个密码（至少 4 位）。」「密码只保护界面上的查看与复制，数据库文件本身未加密。」；「密码」+「确认密码」两个 `*` 掩码输入框；按钮「取消 / 保存」。
  - **输入密码**：标题「输入二级密码」；说明「私密内容需要密码才能查看与复制。」；一个密码输入框；按钮「取消 / 解锁」。
- 错误提示行位于输入框下方，`DANGER` 色；文案：长度不足「密码至少需要 4 位」、两次不一致「两次输入的密码不一致」、错误「密码错误，还可尝试 N 次」、冷却「密码错误次数过多，请 N 秒后再试」。
- 私密卡片状态：未解锁 = `BG_PRIVATE` 底 + 打码 + 🔒 + 「受保护内容，点击输入密码查看」；已解锁 = `BG_PRIVATE` 底保持、🔓、显示真实内容/缩略图，meta 追加「已解锁」；状态栏追加「· 私密已解锁」。

### 4.6 空状态

- 无记录：居中图标 + 「还没有记录」+ 「复制点什么，这里就会出现它的历史」。
- 搜索无结果：「没有找到匹配「关键字」的内容」。

### 4.7 轻提示（toast）

- 底部中央浮出小胶囊（`SUCCESS` / `DANGER` 底，白字，圆角 16），1.5s 自动消失，不阻塞操作。
- 用于「已复制到剪贴板」「已置顶」「已删除」。

## 5. 交互规则

| 操作 | 结果 |
|---|---|
| 单击卡片正文 | 复制内容 → 隐藏窗口 → toast |
| 单击图钉 | 置顶/取消，列表重排，toast |
| 单击删除 | 确认对话框 → 删除记录与文件 → 重排 |
| 滚轮 | 上下滚动列表 |
| `Esc` | 隐藏主窗口 |
| `Ctrl+F` | 聚焦搜索框并全选 |
| `Ctrl+Shift+V`（全局） | 唤出/置前主窗口 |
| 关闭按钮 | 隐藏 + 首次提示 |
| 「彻底退出」 | 结束进程（确认对话框） |
| 私密卡片点击 | 弹密码框；解锁后 5 分钟自动上锁 |

## 6. 文案规范

- 全中文，动词开头，不用感叹号。
- 按钮用 2–4 字：「解锁」「删除」「取消」「彻底退出」「设为置顶」。
- 时间用「今天 / 昨天」优先，超过 7 天用日期。
- 数字与单位间加空格：「236 KB」「1280 × 720」。

## 7. 高 DPI 与窗口

- 启动时 `SetProcessDpiAwareness(2)`；失败则 `SetProcessDPIAware()`。
- `tk scaling` 按屏幕 DPI 设置为 `dpi/72`，保证 125%/150% 下字号正常。
- 窗口居中屏幕；记住上次大小位置（`window_geometry`），恢复时校验是否在可见屏幕内。
